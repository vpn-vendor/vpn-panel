# VPN Panel

Панель управления офисным VPN-шлюзом.

Пока готовится первая тестовая сборка под **Ubuntu 26.04 LTS**. Актуальная установка для клиентов — прежний скрипт (Ubuntu 22.04, две сетевые карты WAN и LAN):

```bash
wget https://raw.githubusercontent.com/vpn-vendor/vpn/main/vpn.sh -O vpn.sh && sudo bash vpn.sh
```

Пакеты новой версии появятся во вкладке Releases.
