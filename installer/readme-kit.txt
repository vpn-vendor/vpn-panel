НОСИТЕЛЬ УСТАНОВКИ ШЛЮЗА VPN PANEL @VERSION@ (для Ubuntu @UBUNTU@)

Что это. Файлы, которые превращают обычную установку Ubuntu @UBUNTU@ в
установку офисного шлюза: диск шифруется, панель и всё нужное ей ставятся
без интернета. Сам образ Ubuntu сюда не входит — скачайте его с
официального сайта Ubuntu (Ubuntu Desktop @UBUNTU@ LTS).

ПРОЧИТАЙТЕ ДО УСТАНОВКИ
- Диск компьютера будет стёрт целиком. Внутренний диск должен быть один.
- Проверьте дату и время в настройках компьютера (BIOS/UEFI). Если часы
  отстают на годы (села батарейка), установщик Ubuntu зависает при
  загрузке — это особенность образа Ubuntu, поправьте дату и повторите.
- Не ставьте Ubuntu обычным способом, чтобы «потом поставить панель»:
  без этих файлов диск не будет зашифрован, и систему придётся
  переустанавливать.
- После установки при каждом включении сервер спрашивает пароль диска на
  своём экране и клавиатуре. Пароль придумаете при первом включении. Его
  нельзя восстановить: забытый пароль — переустановка и восстановление
  настроек из резервной копии панели.

КАК ПОДГОТОВИТЬ ФЛЕШКУ (выберите один способ)

Способ 1 — одна флешка. Запишите образ Ubuntu программой, которая
оставляет флешку доступной для записи (например, Rufus в режиме
«ISO-образ»). Затем скопируйте в корень флешки всё содержимое этого
архива С ЗАМЕНОЙ файлов: файл autoinstall.yaml и папки vpn-panel и boot
должны оказаться рядом с папкой casper. Меню загрузки и экран установщика
будут по-русски.

Способ 2 — две флешки. Первая: образ Ubuntu, записанный любой программой
(Etcher, Rufus, dd). Вторая: любая флешка, отформатированная в FAT32 с
меткой тома CIDATA, в её корень скопируйте всё содержимое этого архива.
При установке обе флешки должны быть вставлены. В этом способе меню и
окно подтверждения остаются от Ubuntu, по-английски: выберите «Try or
Install Ubuntu», затем нажмите «Install».

Способ 3 — для опытных. Соберите один образ сами:
  installer/build-media.sh --deb <пакет.deb> --out <каталог> \
      --iso <официальный ISO Ubuntu> --iso-out <образ шлюза.iso>
Такой образ записывается на флешку любой программой. Ключ --unattended
убирает подтверждение стирания — для массовой установки одинаковых шлюзов.

Способ 4 — панель на уже установленную Ubuntu @UBUNTU@ без интернета.
Ubuntu Server уже стоит, переустанавливать её не хочется, а интернета на
сервере нет. Вставьте в сервер только одну флешку — ту, где лежит папка
vpn-panel (из способа 1 или вторая флешка из способа 2), — и наберите на
его клавиатуре одну строку:

  sudo mount -r /dev/disk/by-id/usb-*part1 /mnt && sudo sh /mnt/vpn-panel/install.sh

Пакеты встанут с флешки, сеть не нужна; диск при этом не стирается и не
шифруется. Если строка ответила «does not exist» — сервер не видит флешку:
вставьте её заново или в другой разъём. Дальше — как после любой
установки: sudo vpn-panel-code печатает адрес и код входа.

ЧТО ПРОИЗОЙДЁТ
1. Загрузитесь с флешки и выберите в меню «Установить шлюз VPN Panel —
   стирает весь диск». Если после этого экран остаётся чёрным или мигает,
   перезагрузите компьютер и выберите «Установить шлюз, если экран чёрный
   или мигает» — это та же установка без драйвера видеокарты. Установщик
   покажет окно «Всё готово к установке» со сводкой настроек — нажмите
   «Установить». Диск будет стёрт, дальше
   установщик всё сделает сам, вопросов больше не будет. Сеть не нужна.
2. После перезагрузки сервер попросит придумать пароль диска (латинские
   буквы, цифры и знаки, от 12 символов) и повторить его.
3. Затем Ubuntu предложит создать учётную запись компьютера — это обычный
   вход в Ubuntu, не пароль диска.
4. На рабочем столе шлюза панель открывается значком «VPN Panel»; из
   офисной сети — в браузере по адресу шлюза, который панель показывает.

Исходный код и обновления: https://github.com/vpn-vendor/vpn-panel
